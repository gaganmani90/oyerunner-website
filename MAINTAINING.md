# Looking after the Oye Runner website

You don't need to know coding. You change the website by **asking Claude in plain words**,
in English or Hinglish. Claude knows how this website works: it reads the instructions in this folder automatically.

## One-time setup (with Gagan's help)

1. Install the **Claude desktop app** and sign in.
2. Gagan connects this website folder to Claude (or gives you access to the GitHub project).
3. That's it. Open Claude, make sure this folder is connected, and start asking.

## How to ask for a change

Just say what you want, the way you'd tell a person. Examples:

| You want to… | Say something like… |
|---|---|
| Change a price | "Annual coaching ka price 21,999 kar do" |
| Add your UPI ID | "Set my UPI ID to mayank@okhdfcbank for payments" |
| Fix a plan | "In the 10K 8-week plan, make week 3 Sunday long run 12 km" |
| Add a race | "Add Mumbai Half Marathon on 15 Aug 2027 with a 21K plan" |
| Hide a finished race | "Navy run ka tab hata do, race ho gaya" |
| Change text | "Change the coach bio to say: …" |
| Add a photo | "Use this photo as the coach photo" (attach the photo) |
| Add an Instagram reel | "Add this reel to the 'Deeper sleep' card: https://instagram.com/reel/…" |
| Add a question | "Add an FAQ: Can I run during Navratri fasting? Answer: …" |
| See it first | "Show me how it looks" |
| Put it live | "Publish it" / "Live kar do" |

Claude will:
1. make the change,
2. check it automatically (it catches mistakes like a price typed as text),
3. tell you what changed,
4. show you a preview if you ask,
5. publish only when you say **"publish"**. The live site updates in about 2 minutes.

## Good habits

- **One change at a time** is easiest to check. You can still ask for several in one message.
- **Always read Claude's summary** before saying "publish", especially for prices and the UPI ID.
- **Training content** (new plans, sessions, safety advice) should be approved by Coach Mayank.
- Made a mistake? Say **"undo the last change"**. Claude can roll back anything that was published.

## If something looks wrong

Tell Claude what you see, e.g. "The TMM tab is showing the wrong date" or "the Pay button isn't working on my phone".
If Claude can't fix it, ask Gagan.

## What Claude won't do without checking with you

Change prices or the UPI ID, delete a plan or a race, change medical/safety wording, or publish.
